
# Project Media

This directory stores visual documentation for the Shrike-Fi three-phase SPWM inverter controller project.

## Directory Structure

```text
media/
├── architecture/
├── waveforms/
└── hardware/
```

## Architecture Diagrams

The `architecture/` directory will contain system block diagrams, signal-flow diagrams, and FPGA–ESP32-S3 interface diagrams.

## SPWM Waveforms

The `waveforms/` directory will contain planned and verified waveform plots, including:

- Three-phase sinusoidal reference signals
- Triangular carrier and PWM comparison
- Six inverter gate-control signals
- Simulated three-phase output voltages
- Measured waveforms, when hardware testing is completed

## Hardware Images

The `hardware/` directory will contain photographs of the Vicharak Shrike-Fi board, prototype hardware, gate-driver circuits, and inverter assembly.

## Documentation Status

These directories are intended for future project evidence. Images and plots will be added as they become available and verified.

**Important:** Conceptual diagrams and simulated results will be identified clearly and will not be presented as measured hardware results.
